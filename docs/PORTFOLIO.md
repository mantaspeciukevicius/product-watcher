# Project summary for LinkedIn

Built and deployed a self-hosted marketplace deal tracker on an Ubuntu home server. The application combines FastAPI, HTMX and SQLite with a Docker-managed monitoring worker and ntfy Android alerts. It supports multilingual filters, currency conversion, price history, favorites and notification deduplication.

The project includes 41 automated tests and a responsive dashboard. Marketplace access is reported honestly: successful reads, limited coverage and access blocks are visible instead of being treated as empty results. Deployment includes persistent storage, local-network authentication and documented recovery procedures.

Repository: https://github.com/mantaspeciukevicius/nvg-deal-tracker

Screenshots show synthetic demonstration data. Browser adapters have partial coverage and marketplace access can change; this is not an endorsement or official integration claim.
